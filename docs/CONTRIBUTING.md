# 변경 제안과 오류 보고

기능 오류나 개선점은 GitHub 이슈로 제안할 수 있습니다. 공개 저장소이므로 실제 출생증명서·이름·생년월일·등록번호·번역 PDF를 첨부하지 마세요. 문제 재현에는 가상 데이터를 사용하고 스크린샷의 개인정보를 가려 주세요.

변경안을 작성하기 전 [LICENSE.md](../LICENSE.md)를 확인하세요. 저장소 공개와 프로젝트 자체의 오픈소스 라이선스 부여는 구분됩니다.

## 확인 항목

- 사용자 입력과 PDF를 외부로 전송하거나 자동 저장하지 않습니다.
- 모바일 화면과 한글 PDF 표시를 확인합니다.
- 기능·설정 변경 시 README와 관련 문서를 갱신합니다.
- 의존성 변경 시 잠금 파일과 제3자 고지문을 함께 갱신합니다.
- 원본 개인정보, 인증정보, 생성 PDF, 테스트 결과를 커밋하지 않습니다.

관리자의 배포 절차는 [운영 안내](MAINTENANCE.md)를 참고하세요.
